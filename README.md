# For My Beautiful Girl ❤️

A romantic React + Vite birthday/love-letter website with:
- floating hearts
- animated couple bears
- two personal photos
- September 21 birthday countdown
- birthday wishes
- love letter
- responsive mobile/iPad/desktop design

## Run in VS Code

1. Open this folder in VS Code.
2. Open Terminal.
3. Run:
   npm install
4. Then:
   npm run dev
5. Open the localhost link shown by Vite.

The two photos are already inside `public/photos/`.

## Change the wording

Open `src/main.jsx` and edit the wishes/reasons/letter text.

## Build for publishing

Run:
npm run build

The production website will be in the `dist` folder.
